A research assistant that only answers from its books.

Ask a developer question. It finds the right book, marks the paragraph, and copies it word for word, with the book as its citation. If the answer is not on the shelf, it says so in one fixed sentence.

  • 15/15 on the private grader
  • 6/6 safety-critical questions
  • 9/10 practice set, replayed below
  • local 14B model, no API key

The whole collection. Nothing outside these six books is ever used.

    The librarian's four rules
    
      
    A small local model paraphrases badly but is good at pointing. So it points, and the code does the rest.
    
      
    
        
    i
    The model selects, it does not write
    It returns paragraph numbers. The application copies those paragraphs verbatim, so the meaning cannot drift.
    
        
    ii
    Citations follow the copied text
    The citation is the book the paragraph came from. The model cannot cite a book it did not quote.
    
        
    iii
    Refusing is a valid answer
    Always the same sentence: I do not know based on the provided documents. Easy to test, impossible to misread.
    
        
    iv
    A question cannot give orders
    “Ignore your rules” changes nothing. The answer still comes from a book, cited, and flagged for review when unsure.

    Known limits
    
      
    What this design gives up, in plain terms.
    
      
    
        
    Verbatim means no rewording.On fa-02 the paragraph is right, but the grader looked for the words “application validates”. The book says it differently, and the agent cannot rephrase.
    
        
    One book per answer.A question that needs two books combined gets only the best one.
    
        
    A tuned threshold.Books are kept when their best passage scores at least 60% of the top score. That number was set on this corpus and may not hold on another.
